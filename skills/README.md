# Project skills

Các skill là tài liệu hướng dẫn ngắn để AI/developer làm đúng quy ước dự án ở những lần tiếp theo.

- `domain-booking`: nghiệp vụ cốt lõi.
- `demo-ui`: cấu trúc prototype HTML/localStorage.
- `razor-migration`: cách port sang ASP.NET Core + PostgreSQL.
- `qa-release`: test/nghiệm thu/release.
